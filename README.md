### 🚀 Featured Projects

* **[🔐 ContextGuard](https://github.com/PGV17/ContextGuard)** 
  Permission-filtered RAG engine with row-level security. 
  *Stack:* FastAPI · pgvector · asyncpg · JWT · sentence-transformers
  *Highlights:* Searches filtered by department & clearance level — zero-trust AI retrieval.

* **[⚙️ Codeforces MCP Server](https://github.com/PGV17/codeforces-mcp-server)** 
  MCP server exposing Codeforces APIs to AI assistants like Claude. 
  *Stack:* TypeScript · MCP SDK · Codeforces API
  *Highlights:* Lets AI tools browse contests, problems & submissions natively.

* **[🗳️ Biometric Voting](https://github.com/PGV17/biometric-voting)** 
  Secure digital voting system with biometric identity verification. 
  *Stack:* JavaScript · Biometric APIs
  *Highlights:* Tamper-resistant vote recording with identity binding.
